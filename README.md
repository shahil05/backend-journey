# backend-journey

My 6-month plan to learn Java + Spring Boot backend with AI features. Building in public, one commit at a time.

**Start date:** 26 Oct 2026 (Week 1)  
**Stack:** Java 21, Spring Boot, PostgreSQL, Redis, Kafka, Docker, GitHub Actions, Spring AI / LangChain4j

## Plan

### Month 1: Java for backend and how the web works
**Project:** Expense Tracker (CLI) and an LLM command-line client

- Week 1: Modern Java, the backend way (ship: Expense domain + stream reports pushed to GitHub)
- Week 2: Errors, files and clean layers (ship: CLI Expense Tracker v1 with tests)
- Week 3: How the web actually works (ship: Java LLM command-line client)
- Week 4: SQL and databases, the interview-ready core (ship: Expense Tracker v2 on PostgreSQL)

### Month 2: Spring Boot core
**Project:** URL Shortener API (like bit.ly) with an AI summary feature

- Week 5: Why Spring? Dependency Injection from first principles (ship: Shortener v0 running locally)
- Week 6: Save data with JPA and Hibernate (ship: Shortener v1 with database and migrations)
- Week 7: Make the API professional (ship: Polished API, Postman collection, Swagger docs)
- Week 8: Your first AI endpoint (and Month 2 close) (ship: Shortener v2 with AI summary and tags)

### Month 3: Security, testing and AI in a real API
**Project:** Task and Project Manager API with an AI planner

- Week 9: Who are you? Authentication (ship: Login and protected routes working end to end)
- Week 10: What are you allowed to do? Authorization and API security (ship: Role-based Task API and security checklist)
- Week 11: Prove it works: testing (ship: Green CI badge in README)
- Week 12: AI in a real API: chat, streaming, cost and safety (ship: AI planner endpoint with quota)
- Week 13: Month 3 consolidation and mock interview (ship: Task Manager API complete with README)

### Month 4: Real-world data problems and RAG
**Project:** E-commerce backend and Ask-My-Docs (RAG service)

- Week 14: Money and stock: transactions that do not lie (ship: Order placement that never oversells)
- Week 15: Concurrency and speed: threads and Redis (ship: E-commerce v1 with Redis and a concurrency test)
- Week 16: Embeddings and vector search: the idea behind RAG (ship: Ask-My-Docs v0 answering from your documents)
- Week 17: Make RAG good: evaluation and quality (ship: Ask-My-Docs with measured quality)

### Month 5: Async, Docker, deploy and AI agents
**Project:** Event-driven e-commerce, live deployment, Shop Assistant agent

- Week 18: Do slow work later: messaging (ship: Event-driven order confirmation)
- Week 19: Ship it: Docker and CI/CD (ship: Live deployed URLs for two projects)
- Week 20: AI agents and tool calling (ship: Shop Assistant agent with safe tools)
- Week 21: Scale thinking and Month 5 consolidation (ship: Performance report in the repo)

### Month 6: Capstone, system design and job-ready
**Project:** Ticket Booking System with an AI concierge

- Week 22: Capstone design: Ticket Booking System (ship: Design doc and project skeleton)
- Week 23: Capstone build: holds, payments and expiry (ship: Double-booking-proof flow)
- Week 24: Capstone AI: concierge and smart search (ship: AI concierge feature)
- Week 25: System design, load testing and polish (ship: Polished capstone live)
- Week 26: Job-ready sprint (ship: Resume updated and applications sent)
